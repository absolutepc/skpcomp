## Исправления в ходе аудита

1. **CI / FPS:** тесты проверяют актуальные компоненты `product-detail-page.tsx` и `ready-pc-mobile-detail.tsx`, а не удалённую старую разметку `shop.tsx`.
2. **Характеристики:** лимит количества записей `specs` теперь рассчитывается по категории с запасом для дополнительных полей, а не фиксирован на 80. Это важно для мониторов с 87 параметрами.
3. **Игровые изображения:** восстановлена загрузка PNG/JPEG/WebP через админку и отдельные R2-ключи `fps-games/<gameId>/<uuid>`; проверяются ID игры, размер и сигнатура файла.
4. **Навигация:** добавлены доступные текстовые названия значкам корзины и избранного, а также `aria-expanded` и `aria-controls` мобильному меню.
5. **Автотесты:** в CI включены ранее не запускавшиеся тесты брендов/цветовых вариантов/пресетов GPU, проверки статической структуры 18 разделов и реальная интеграционная проверка медиа.
6. **Проверка ассетов:** ключевые изображения категорий, логотип и стандартные обложки FPS должны физически присутствовать в `public/images`.

## Оставшиеся риски

### P1 — перед публикацией / при активном использовании

- **Конкурентное редактирование каталога.** `/api/store` сохраняет весь каталог единым JSON-документом без версионного номера и проверки конфликта. Если два администратора редактируют одновременно, последнее сохранение может перезаписать чужую работу. Рекомендация: optimistic locking по `revision` и предупреждение о конфликте.
- **Визуальное качество не подтверждено браузером.** Приоритет: iOS Safari, macOS Safari, Chrome desktop; реальные ширины 320/375/390/430/768/1024/1440/1920 px и реальные фотографии из D1/R2.

### P2 — качество, безопасность и удобство

- **Временный доступ без пароля** в `NODE_ENV=development` на приватном IP: допустим лишь на доверенной Wi-Fi-сети; для удалённого или публичного доступа использовать пароль. Production-режим остаётся защищённым.
- **Закрытие редактора товара по явной кнопке X** сейчас может отбросить несохранённые изменения без предупреждения; закрытие по фону уже отключено. Полезно добавить подтверждение при «грязной» форме.
- **Единая CSS-база:** `app/globals.css` крупная, много исторических медиаправил. Рекомендуется проверить специфичность и убрать дубли, чтобы изменения одного экрана не ломали другой.
- **Реальная мобильная загрузка** PNG/WebP через Safari и JPEG обложек FPS — отдельная ручная проверка после интеграционных тестов.
- **Неавтоматизированная доступность**: VoiceOver, размер интерактивных зон, контраст, фокус-ловушки модальных окон, поведение клавиатуры.
