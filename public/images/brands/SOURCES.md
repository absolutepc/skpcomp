# Brand mark sources

Marks identify the respective product manufacturers and series. Trademarks remain with their owners. Artwork is stored locally; monochrome display is applied with CSS, and transparent padding is removed where necessary.

- ASUS, AMD, Intel, NVIDIA, Samsung, Kingston: https://github.com/simple-icons/simple-icons/tree/develop/icons (CC0 icon collection).
- ASRock: https://github.com/selfhst/icons/blob/main/svg/asrock-light.svg (brand artwork).
- MSI: official vector wordmark from `MSI-logo-horiz-cmyk-wht-for-screen.ai` in https://download.msi.com/archive/mnu_exe/corp/msi-logos.zip?v=1.0 (https://www.msi.com/page/msi-logos). Converted vector paths to SVG; transparent padding removed.
- MAG / MPG / MEG: https://www.msi.com/Landing/gaming-redefined-style-perfected — `https://storage-asset.msi.com/event/2024/CND/gaming-rederined/images/logo-{mag,mpg,meg}.webp`.
- GIGABYTE: inline GIGABYTECiLogo SVG from https://www.aorus.com/.
- AORUS: https://logo-teka.com/wp-content/uploads/2026/03/aorus-horizontal-logo.svg
- ROG: https://rog.asus.com/rog/nuxtStatic/img/logo-rog.svg
- TUF: https://www.asus.com/campaign/tuf-gaming/img/index/index_bg_1.svg
- PALIT: https://www.palit.com/file/images/Logo_w.svg
- DeepCool: https://cdn.deepcool.com/public/new/Design/Header/LOGO/logo_pc_BK.svg
- Logitech: https://www.logitechg.com/content/dam/logitech/en/nav/brand-logos/logitech.svg
- AULA: https://www.aulastar.com/uploads/allimg/20230921/1-2309212124532Z.png
- XPG: four original logo paths extracted from page 1 of the manufacturer's product catalog, mirrored at https://gzhls.at/blob/ldb/8/2/a/c/f6586bf665505b7c56dd93f8375957881806.pdf.

Raster source marks are resized for compact UI display and embedded as PNG in self-contained SVG wrappers. No runtime requests to these sources are required.
